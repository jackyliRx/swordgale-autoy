# 回程／返回起點 API 摘要

## 已觀察請求

| 欄位 | 值 |
| --- | --- |
| 方法與端點 | `POST /api/move/0` |
| Request body | 未觀察到 |
| HTTP 狀態 | 200 |
| 回傳位置 | 大草原，第 1 層 |
| 角色狀態 | 回傳英雄 `actionState: 1`，並有新的 `actionCompleteTime` |

回應也包含 `heroes`、`canBack`、`canForward` 與冷卻時間。此筆資料只包含一名角色，尚不能推斷多角色隊伍的完整影響；回傳位置是大草原第 1 層，不能據此宣稱傳送至城鎮。

## Autoy 行為

任一角色符合死亡或死透判定時，介面提供「回程／返回起點」。點擊前顯示角色名稱並要求確認；送出後重新讀取 `/heroes` 與 `/huntInfo`，自動狩獵保持停止，直到使用者檢視狀態並手動重新啟動。

移動中的角色會顯示伺服器回傳的完成時間。到期後 Autoy 重新讀取狀態；只有新資料回報 `actionState: 1` 且 `canComplete: true` 才顯示「完成移動」。該操作呼叫 `POST /api/move/complete`（無 request body），回應位置是「初始之鎮」，`huntZone: 0`、`huntStage: 0`，角色回到 `actionState: 0`。完成後再次讀取 `/heroes` 和 `/huntInfo`，不自動恢復狩獵。
