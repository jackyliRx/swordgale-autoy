# 回程／返回起點 API 摘要

## 已觀察請求

| 欄位 | 值 |
| --- | --- |
| 方法與端點 | `POST /api/move/0` |
| Request body | 未觀察到 |
| HTTP 狀態 | 200 |
| 回傳位置 | 大草原，第 1 層 |
| 角色狀態 | 回傳英雄 `actionState: 1`，並有新的 `actionCompleteTime` |

回應也包含 `heroes`、`canBack`、`canForward` 與冷卻時間。此筆資料只包含一名角色，尚不能推斷多角色隊伍的完整影響；回傳位置是大草原第 1 層，不能據此宣稱傳送至城鎮。

## Autoy 行為

自動狩獵偵測到出戰角色死亡或死透時，暫停所有狩獵請求，並由該帳號 runner 自動處理移動。流程先送出 `POST /api/move/0`，依伺服器的 `actionCompleteTime` 等待，重新讀取資料並確認全隊都可完成後，送出 `POST /api/move/complete`。

若完成回程後位置是初始之鎮（`huntZone: 0`, `huntStage: 0`），Autoy 會呼叫已觀察成功的 `POST /api/move/1`。本機紀錄顯示 4 名英雄進入移動狀態，仍在城鎮並回傳完成時間；完成移動後的另一筆紀錄確認抵達大草原 `1/1`。程式會檢查完成後位置，若目的地不符便停止，不會呼叫狩獵。詳細紀錄見 `前往-大草原.md` 與 `完成移動.md`。

`/move/0` 完成後也可能已在大草原第 1 層（`huntZone: 1`, `huntStage: 1`），此時不再移動。兩種位置都以最新 `/huntInfo` 判斷。抵達大草原後 runner 停止；死亡角色仍須一般死亡「全部重生」或死透「個別轉生」，不會以死亡角色繼續狩獵。
