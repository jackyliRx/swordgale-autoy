# 前往大草原 API 摘要

## 已觀察請求

| 欄位 | 值 |
| --- | --- |
| 方法與端點 | `POST /api/move/1` |
| HTTP 狀態 | 200 |
| 請求時間 | `2026-09-25T19:29:37.997Z` |
| 耗時 | 約 64 ms |
| Request body | 錄製資料未見 request body |
| Response 位置 | 初始之鎮 `huntZone: 0`, `huntStage: 0` |
| Response 英雄 | 4 名英雄皆為 `actionState: 1`，預定完成時間 `2026-09-25T19:30:38.095Z` |
| Response 移動狀態 | `canBack: false`, `canForward: false` |

來源是使用者提供的 Console 訊息，以及本機 `前往-大草原` recorder 記錄。Console 摺疊摘要顯示 POST 200；完整本機記錄補足初始之鎮位置、4 名英雄的移動狀態與完成時間。本文僅保留去識別化欄位；原始 recorder 完整匯出可能包含帳號資料，提交前須先移除 token、個人及角色識別資料。

## Autoy 行為

本次錄製確認呼叫後角色仍在初始之鎮 `0/0`，但 4 名角色開始移動（`actionState: 1`）；需依 `actionCompleteTime` 等待。自動狩獵死亡回城流程會重新讀取並確認全隊 `canComplete: true` 後，才呼叫 `POST /api/move/complete`。最新完成移動紀錄確認最終可抵達大草原 `1/1`；位置不符或請求失敗時停止 runner，不會繼續狩獵。
