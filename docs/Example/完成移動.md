# 完成移動 API 摘要

| 欄位 | 已觀察值 |
| --- | --- |
| 方法與端點 | `POST /api/move/complete` |
| Request body | 未觀察到 |
| HTTP 狀態 | 200 |
| 回傳位置 | 依情境不同：初始之鎮 `0/0`，或大草原第 1 層 `1/1` |
| 角色狀態 | 回應中的角色 `actionState: 0` |
| 後續讀取 | `GET /api/zoneUsers` |

兩筆「完成移動」紀錄都回傳 `actionState: 0`，但目的地不相同：較早紀錄在初始之鎮（`huntZone: 0`, `huntStage: 0`, `canForward: false`）；「完成移動-大草原.js」在大草原第 1 層（`huntZone: 1`, `huntStage: 1`, `canForward: true`）。因此不可假設完成移動必定回城；以該次 POST 回應和最新 `/huntInfo` 為準。

Autoy 僅在新鮮角色資料回報 `actionState: 1` 與 `canComplete: true` 時顯示「完成移動」。完成後重新讀取 `/heroes` 和 `/huntInfo`，並讓自動狩獵維持停止。
