# 回城（啟動移動）API 錄製摘要

來源：Tampermonkey Recorder 匯出 `回城.json`，共一組 request／response 配對。

## 已觀察請求

| 欄位 | 值 |
| --- | --- |
| 操作 | 遊戲介面「回城」 |
| 方法與端點 | `POST /api/move/0` |
| Request body | 無 |
| HTTP 狀態 | 200 |
| 耗時 | 60 ms |
| 回應英雄數 | 2 |
| 回應位置 | 大草原 `huntZone: 1`, `huntStage: 1` |
| 回應移動狀態 | 兩名英雄均為 `actionState: 1` |
| `actionCompleteTime` | 約在請求後 60 秒 |
| `canBack` / `canForward` | `false` / `true` |

## 判讀與待確認

這筆資料證明按下「回城」會送出 `POST /api/move/0`，並讓兩名英雄進入移動狀態。回應當下的位置仍是大草原第 1 層，因此不能把這個 POST 的即時回應當成已抵達城鎮。

需再手動完成移動並錄製 `POST /api/move/complete` 的 request／response，再以回應及最新 `GET /api/huntInfo` 確認最終目的地。Autoy 必須依 `actionCompleteTime` 等待、重新讀取狀態並確認可完成後，才能送出完成移動請求；目的地以完成後的最新狀態為準。

原始 JSON 保留本機，不提交 GitHub。此摘要不記錄英雄名稱、ID 或狀態效果細節。
