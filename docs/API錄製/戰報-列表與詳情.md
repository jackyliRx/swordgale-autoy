# 狩獵戰報列表與詳情 API 錄製摘要

來源：Tampermonkey Recorder 匯出 `autoy-api-recorder-2026-09-26T11-50-29-184Z.json`。摘要省略帳號、角色名稱與完整戰報內容。

## 已確認請求

| 操作 | 方法與端點 | 回應用途 |
| --- | --- | --- |
| 讀取狩獵戰報列表 | `GET /api/reports?type=hunt` | 回傳 `reports` 陣列；每筆含 `id`、`zoneName`、`stage`、`time`、`dead`。 |
| 標記單筆已閱 | `POST /api/reports/{reportId}/view` | HTTP 200，回傳 `{ ok: true }`。僅在使用者手動點選單筆時呼叫。 |
| 讀取單筆戰報 | `GET /api/reports/{reportId}` | 回傳 `report` 的地圖、樓層、時間、我方／敵方陣容與 `messages`。 |

## UI 使用規則

- 開啟「戰報」彈窗不讀取 API；使用者按「讀取戰報」才請求列表。
- 點選戰報後才依序送出標記已閱與詳情讀取；不自動逐筆讀取歷史戰報。
- 摘要在瀏覽器本地依戰報欄位與訊息計算我方／敵方人數、造成／承受傷害、擊殺、死亡與關鍵事件，不送資料到外部服務。
- 這是閱讀功能，不加入自動狩獵排程。
