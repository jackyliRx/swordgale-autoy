# 前往大草原（啟動移動）API 錄製摘要

來源：Tampermonkey Recorder 匯出 `前往大草原.json`，共一組 request／response 配對。

## 已觀察請求

| 欄位 | 值 |
| --- | --- |
| 操作 | 遊戲介面「前往大草原」 |
| 方法與端點 | `POST /api/move/1` |
| Request body | 無 |
| HTTP 狀態 | 200 |
| 耗時 | 66 ms |
| 回應英雄數 | 2 |
| 回應位置 | 初始之鎮 `huntZone: 0`, `huntStage: 0` |
| 回應移動狀態 | 兩名英雄均為 `actionState: 1` |
| `canBack` / `canForward` | `false` / `false` |

## 判讀與待確認

此請求會啟動從初始之鎮前往大草原的移動；回應中的位置仍是起點 `0/0`，不能視為已抵達。下一步需等角色可完成移動後手動按「完成行動」，錄製 `POST /api/move/complete`，再以完成回應與最新 `GET /api/huntInfo` 確認目的地。

移動參數 `1` 是操作端點的一部分，不應直接當成地圖 ID。地圖資料和起訖點路線需分開管理，並在路線完成後驗證實際座標。

原始 JSON 僅留本機；摘要不保存英雄識別資料。
