## 回應重點

回應包含 `report`、`huntInfo`、`equipmentChanges`、`money`、`huntCount`：

- `report.stage` 與 `huntInfo.huntStage` 都維持大草原第 2 層，確認本次沒有前行。
- `huntInfo.heroes` 回傳 4 名英雄，更新本次戰鬥後的隊伍快照。
- 戰報有 9 筆訊息。
- `huntInfo.canForward: true`；回傳新的 `huntAvailableAt` 與 `attackAvailableAt`。
- 本次 `equipmentChanges.updated` 與 `deletedIds` 都為空。
- `huntCount` 回傳最新帳號狩獵累計數。

## 使用規則

完整 `/api/heroes` 已確認勾選出戰角色 1–4 名、全員存活空閒、HP/SP 達門檻，且目前樓層等於目標樓層時，Autoy 才送出一次 `POST /api/hunt`。成功後以回應的 `huntInfo` 更新隊伍與冷卻，等待伺服器 `huntAvailableAt` 後重新讀取狀態。

本次 `huntInfo.heroes` 是縮減資料且不含 `selected`；出戰名單仍以完整 `/api/heroes` 為權威資料。
