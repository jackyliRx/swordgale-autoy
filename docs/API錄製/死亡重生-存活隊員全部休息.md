# 死亡重生期間：存活出戰角色全部休息

來源：本機錄製檔 `死亡重生-存活隊員全部休息.json`；原始內容不提交。

## 狀態與流程

一名出戰角色一般死亡並進入 `actionState: 3` 重生，其他已勾選出戰角色已回到初始之鎮且閒置。

1. 對存活、已勾選且閒置的出戰角色送出 `POST /api/heroes/restAll`。
2. 依重生與休息的最晚 `actionCompleteTime` 等待。
3. 重生可完成時送出 `POST /api/heroes/reviveAll/complete`。
4. 休息可完成時送出 `POST /api/heroes/restAll/complete`。
5. 重新讀取角色與狩獵狀態，接續前往大草原及自動狩獵。

## 保護條件

- 休息只處理 `selected: true`、存活且閒置的出戰角色。
- 帳號批次重生仍等待帳號內全部一般死亡角色。
- 完成時間未到或 `canComplete` 尚未成立時，只排程下次檢查。
- 存活出戰角色有未知行動時停止 runner。
