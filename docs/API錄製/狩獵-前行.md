# 狩獵－前行（Tampermonkey 錄製）

來源：本機原始錄製檔 `狩獵-前行.json`。原始檔包含英雄與戰報資料，只保存本機，不提交公開 GitHub。

## 已確認請求

| 項目 | 值 |
| --- | --- |
| 操作 | 狩獵－前行 |
| 方法與端點 | `POST /api/hunt?type=forward` |
| Request body | 無 |
| HTTP 狀態 | 200 |
| 耗時 | 75 ms |

## 回應重點

回應包含 `report`、`huntInfo`、`equipmentChanges`、`money`、`huntCount`：

- `report.stage` 與 `huntInfo.huntStage` 都為第 2 層；區域為大草原。
- `huntInfo.heroes` 回傳 4 名英雄，代表本次戰鬥結果已套用到隊伍快照。
- `huntInfo.canForward: true`，可再前行。
- `huntAvailableAt` 與 `attackAvailableAt` 是伺服器回傳的下一次狩獵與攻擊時間。
- 戰報包含 11 筆訊息；`huntCount` 回傳最新帳號狩獵累計數。

## 使用規則

只有完整 `/api/heroes` 已確認勾選出戰角色 1–4 名、全員存活空閒、HP/SP 達門檻，且最新 `/api/huntInfo` 為 `canForward: true` 時，Autoy 才能送出一次前行狩獵。成功後以回應的 `huntInfo` 更新隊伍、樓層與冷卻時間，下一回合必須等待 `huntAvailableAt` 並重新讀取狀態。

本次 `huntInfo.heroes` 是縮減資料且未含 `selected`；出戰名單仍以完整 `/api/heroes` 為權威資料。
