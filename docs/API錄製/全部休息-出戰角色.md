# 全部休息－出戰角色（Tampermonkey 錄製）

來源：本機原始錄製檔 `全部休息-出戰角色.json`。原始檔包含英雄資料，只保存本機，不提交公開 GitHub。

## 已確認請求

| 項目 | 值 |
| --- | --- |
| 操作 | 全部休息 |
| 方法與端點 | `POST /api/heroes/restAll` |
| Request body | 無 |
| HTTP 狀態 | 200 |
| 耗時 | 62 ms |

## 回應重點

回應直接回傳狩獵狀態與 `heroes`：

- 回傳 4 名英雄，全部 `actionState: 2`，表示進入休息。
- 4 名英雄的 `actionStart` 與 `actionCompleteTime` 相同；本次完成時間比開始時間晚 60 秒。
- 回應仍在大草原第 1 層，`canForward: true`。
- 各英雄都有 `statuses` 陣列，但這份樣本都為空。

## 使用規則

Autoy 以伺服器回傳的 `actionCompleteTime` 排程完成休息，不把 60 秒寫死。到期後先重新讀取完整 `/api/heroes`，確認目前勾選出戰角色全數仍為 `actionState: 2` 且 `canComplete: true`，再呼叫 `POST /api/heroes/restAll/complete`。

本次 `heroes` 為縮減資料，沒有 `selected` 欄位；它不能單獨證明 4 名回應英雄就是當下勾選出戰角色，選取名單仍以完整 `/api/heroes` 為準。
