# 狩獵－死亡 API 錄製摘要

來源：Tampermonkey Recorder 匯出 `狩獵-死亡.json`，共兩組 request／response 配對。

## 已觀察狩獵結果

| 方法與端點 | HTTP | 耗時 | 結果 |
| --- | --- | --- | --- |
| `POST /api/hunt?type=forward` | 200 | 74 ms | 大草原第 5 層的前行狩獵；回傳兩名出戰英雄的戰鬥狀態與戰報。 |
| `GET /api/zoneUsers` | 200 | 70 ms | 狩獵後更新區域玩家資料；不保留玩家清單。 |

戰報確認其中一名英雄被擊殺。`huntInfo.heroes` 顯示該英雄 `hp: 0`、`perished: false`、`actionState: 0`；另一名英雄存活。此回應沒有 `selected` 欄位，因此名單仍須以完整 `GET /api/heroes` 為準。

伺服器回傳新的 `huntAvailableAt` 和 `attackAvailableAt`。自動流程需要先判定隊伍死亡狀態，再決定是否進入復原，不可以只依狩獵 POST 的 HTTP 200 判斷隊伍安全。

原始 JSON 僅留本機；本摘要省略角色名稱、ID 與戰報全文。
