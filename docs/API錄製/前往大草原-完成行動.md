# 前往大草原－完成行動 API 錄製摘要

來源：Tampermonkey Recorder 匯出 `前往大草原-完成行動.json`，共兩組 request／response 配對。

## 已觀察流程

| 順序 | 方法與端點 | HTTP | 耗時 | 結果 |
| --- | --- | --- | --- | --- |
| 1 | `POST /api/move/complete` | 200 | 62 ms | 兩名英雄完成移動並進入 `actionState: 0`；抵達大草原 `huntZone: 1`, `huntStage: 1`，`canForward: true`。 |
| 2 | `GET /api/zoneUsers` | 200 | 66 ms | 完成移動後遊戲另讀取區域玩家資料；摘要不保留玩家清單。 |

啟動此段移動的資料見 [前往大草原](前往大草原.md)：從初始之鎮 `0/0` 呼叫 `POST /api/move/1`，兩名英雄進入 `actionState: 1`；啟動回應仍顯示起點座標。完成後才確認抵達大草原 `1/1`。

## Autoy 使用規則

`POST /api/move/complete` 無 request body。呼叫前應以最新狀態確認出戰英雄都在移動且可完成；呼叫後依 `huntZone`、`huntStage`、`zoneName` 和英雄 `actionState` 驗證，再讀取最新 `/api/huntInfo`。本次確認城鎮到大草原的路線完成結果為 `1/1`。

原始 JSON 僅留本機；摘要不保存英雄識別資料或 `/api/zoneUsers` 玩家內容。
