# 回城－完成行動 API 錄製摘要

來源：Tampermonkey Recorder 匯出 `回城-完成行動.json`，共兩組 request／response 配對。

## 已觀察流程

| 順序 | 方法與端點 | HTTP | 耗時 | 結果 |
| --- | --- | --- | --- | --- |
| 1 | `POST /api/move/complete` | 200 | 86 ms | 兩名英雄移動完成並進入 `actionState: 0`；抵達初始之鎮 `huntZone: 0`, `huntStage: 0`，`zoneName: 初始之鎮`。 |
| 2 | `GET /api/zoneUsers` | 200 | 70 ms | 移動完成後遊戲另讀取區域玩家資料；摘要不保留玩家清單。 |

本次完成操作前的移動啟動錄製見 [回城](回城.md)：`POST /api/move/0` 回應兩名英雄為 `actionState: 1`，完成時間約在請求後 60 秒，當時座標仍為大草原 `1/1`。

## Autoy 使用規則

`POST /api/move/complete` 無 request body。呼叫成功後，應以回應中的 `huntZone`、`huntStage`、`zoneName` 和英雄 `actionState` 確認完成結果，並再讀取最新 `/api/huntInfo`。本次樣本確認完成後回到初始之鎮 `0/0`，但其他移動情境仍應以各次 API 回應判定，不可假設目的地固定。

原始 JSON 僅留本機；本摘要不保存英雄識別資料或 `/api/zoneUsers` 玩家內容。
